# Complete selected scientific body prose: wider validation, not a new extraction gain

The earlier diagnostic selected abstracts and up to eight direct paragraphs of the
first body section. This separate reference selection retains the first complete
abstract and every direct body/recursively nested section paragraph from the same
three original publisher PDF/XML pairs:33recent PLOS,93next PLOS,17eLife,143total.
Figures/tables/boxed text/back matter/subarticles stay outside this explicit prose
selection. Counts/complete paragraph hashes/order are frozen before candidate runs.
No easier replacement source, source/reference repair or candidate-dependent trimming.
These already observed development papers are not new held-out acceptance evidence.

The same strict evaluator preserves all inline publisher text and collapses only
ASCII whitespace. Publisher XML text may differ from physical PDF text; formula
alternatives, hard hyphens, NBSP and source/version differences are not repaired.
This is exact paragraph presence/order evidence, not visual segmentation or general
recognition accuracy. Repeated occurrences cannot receive invented order assignments.
