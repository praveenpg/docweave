## Added

An explicit native PDF table policy, `RULED_AND_PARTIAL_TEXT`, recognizes a constrained
subset of partially ruled tables with multilevel headers. It uses a full-width top rule,
matching segmented separator/bottom rules, complete regularly spaced body rows and at least
one numeric body column. Header spans and cell areas are labelled as inferred geometry.

```java
var options = dev.docweave.partition.PdfOptions.defaults()
        .withTableDetection(dev.docweave.partition.PdfOptions.TableDetection.RULED_AND_PARTIAL_TEXT)
        .withTableCellCoordinates(true);
var registry = dev.docweave.partition.PartitionerRegistry.of(java.util.List.of(
        dev.docweave.partition.PdfPartitioner.create(options)));
var result = dev.docweave.DocWeave.create(registry).partition(java.nio.file.Path.of("report.pdf"));
```

## Upgrade and compatibility

Use `io.docweave:docweave-pdf:0.1.0-beta.5` for PDF-only use,
or `io.docweave:docweave:0.1.0-beta.5` for the convenience dependency. Align all explicitly
selected DocWeave modules to the same version. Optional OCR and ONNX adapters remain separate.

Java21 or later is required; Java21 and25 are verified. Java packages remain `dev.docweave`.
Existing defaults and earlier native table policies are unchanged. The new policy is opt-in,
adds no dependency, and invokes no OCR, model, network download or additional executor.

## Known limitations

Header spans follow source run geometry and do not establish semantic merges. Missing or
wrapped body cells, prose-only data without a complete numeric column, conflicting rules,
intersecting images and nonupright text can cause fallback to ordinary native text. No general
borderless, damaged-grid, noisy-scan, semantic reading-order or calibrated-confidence guarantee
is added. Existing procurement spacing differences and broad PDF quality gates remain open.

The [feature contract](../pdf-support.md#explicit-partially-ruled-tables-with-multilevel-headers),
